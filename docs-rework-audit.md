# Graftcode documentation rework audit

## Scope and method

This audit covers every Markdown page currently under `docs/` on branch `feature/rework-documentation`: 43 content pages plus `docs/README.md`.

Claims were checked statically against implementation and tests in `D:\GRAFTCODE\GraftingAgent`. Tests were inspected but not executed. A statement is not treated as verified merely because another documentation page repeats it.

Severity:

- **Critical**: security, compatibility, or operational guidance can cause an unsafe or non-working implementation.
- **High**: the page materially misstates current behavior or blocks a developer from completing a task.
- **Medium**: the content is directionally useful but duplicated, abstract, or missing essential constraints.
- **Low**: structure, terminology, or maintenance issue with limited immediate risk.

Confidence:

- **High**: direct implementation and test evidence.
- **Medium**: implementation evidence exists but does not cover every runtime or deployment mode.
- **Low**: only prose, roadmap language, or an external service supports the claim.

9. Publish MCP only from an E2E-tested flow.
10. Remove performance, cost, and enterprise claims until their evidence packages exist.
