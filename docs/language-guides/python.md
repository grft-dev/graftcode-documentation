# Python

## Support status and direction

**Provider: supported. Consumer: supported.** Python has module analysis, PyPI-compatible package
generation, generated config tests, and cross-runtime public and virtual E2E coverage. Python 2.7 is
listed as a legacy Gateway host mode; this guide covers Python 3 only.

## Prerequisites

- Python 3.6+ per Gateway runtime support; prefer a currently supported Python release.
- A module/package with complete public type hints and package metadata.
- `pip` and a current [Graftcode Gateway](https://github.com/grft-dev/graftcode-gateway/releases).

## Provider support

Point Gateway at the module directory containing the source and metadata:

```bash
gg --runtime python --modules ./pricing/
```

Keep test scripts and unrelated public functions outside that directory. Confirm discovery in Vision.

## Consumer support

Python consumers receive a pip-installable generated package. The generated configuration API uses
class attributes `GraftConfig.host`, `GraftConfig.stateless`, and `GraftConfig.module`. Generated
method and import shapes vary with the provider; copy them from Vision.

## Package manager

pip with a PyPI-compatible extra index generated by Gateway.

## Minimal provider example

```python
class PriceService:
    @staticmethod
    def calculate(base_price: float, discount_percent: float) -> float:
        return base_price * (1 - discount_percent / 100)
```

Type every public parameter and return value. Prefix non-contract helpers with `_`.

## Minimal consumer example

The generator verifies the config syntax below. The exact service import is dynamic:

```python
from <generated_package_path>.graft_config import GraftConfig
from <generated_service_path> import PriceService

GraftConfig.host = "ws://localhost/ws"
GraftConfig.stateless = True

price = PriceService.calculate(100.0, 15.0)
print(price)
```

Some generated cross-runtime methods can be awaitable. Follow the generated package and Vision
snippet; do not add or remove `await` based on this illustrative same-language example.

## Installation

1. Run Gateway against the provider module directory and wait for publication.
2. Open Vision's PyPI configuration or the PyPI route emitted by that Gateway.
3. Copy the complete `python -m pip install` command, including the generated extra-index URL,
   normalized package name, and version.
4. Execute it unchanged in the intended virtual environment.
5. Copy the exact import paths and invocation form from Vision.

Do not derive Python import names from distribution names; hyphen/underscore and nested namespace
normalization is generator-owned.

## Configuration

```python
GraftConfig.host = "wss://service.example/ws"
GraftConfig.stateless = True
```

Defaults are `host = "inmemory"` and `stateless = False`. The inspected generator also verifies
`set_headers(...)`, `invoke_with_headers(...)`, and asynchronous scoped-header invocation. Configure
before the first call.

## Supported types

Verified portable baseline:

- `str`, `int`, `float`, and `bool`;
- simple classes with stable, typed fields;
- homogeneous `list[T]` values.

Prefer dataclasses/simple DTOs composed from that baseline. Avoid `Any`, untyped `object`, `dict` maps,
sets, tuples, iterators, generators, bytes, NumPy/Pandas objects, file handles, callbacks, framework
objects, `datetime`, and `UUID` on the public boundary. Use lists, ISO-8601 strings, and string IDs.

**Gap:** optional/union values, enums, generic models, async providers, decorators other than ordinary
method decorators, and complex inheritance are not exhaustively verified.

## Runtime-specific limitations

- Dynamic Python shapes still need type hints for deterministic generated clients.
- Public names in the hosted directory can be discovered unintentionally.
- Distribution names and import paths are often different.
- Some test runners use explicit process termination because native runtime threads can keep a Python
  process alive; treat a post-call hang as a runtime cleanup issue, not automatically an invocation
  failure.
- Stateful instances require affinity; prefer static methods or module functions.

## Troubleshooting

- **Odd or missing generated signature:** add precise type hints and simplify the public shape.
- **Import error after installation:** use the exact nested import emitted by Vision.
- **Client loads a local module:** set `GraftConfig.host`.
- **Unexpected methods exposed:** isolate the provider directory and `_`-prefix helpers.
- **Process does not exit after a successful script:** confirm the result first, then investigate
  native runtime thread cleanup.
