# Enterprise self-hosted engine

An enterprise self-hosted Graftcode Engine is not documented as a currently available capability.

The documentation audit found no versioned deployment artifact, available SKU, installation procedure, architecture, upgrade policy, support policy, marketplace listing, or security/compliance evidence for the previously described offering. Do not plan a deployment or make procurement, residency, or compliance commitments based on this legacy route.

This page is retained only to preserve the old URL. A current offering should be documented only after its product owner publishes deployable artifacts and release-qualified operational and security guidance.

For the currently documented local host component, see [Graftcode Gateway](../core-concepts/graftcode-gateway.md). Gateway hosting is not equivalent to self-hosting the package-generation and metadata services previously described here.
