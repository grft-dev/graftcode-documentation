# How Grafts are generated

This topic moved to [Package generation](../core-concepts/package-generation.md).

The canonical page follows the verified path from module analysis and Unified Graft Model (UGM) storage through target-language code generation and package construction. It also separates generated wrappers from user-written provider and consumer code.

Package names, registry paths, versions, caching policy, and install commands are not universal conventions. Obtain the exact install command from the current Gateway or Vision output.
